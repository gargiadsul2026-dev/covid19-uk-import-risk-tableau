# COVID-19 UK Import Risk Dashboard

**CS5703 Data Visualisation | Brunel University London | 2026**

An interactive Tableau dashboard analysing which countries pose
the greatest COVID-19 import risk to the United Kingdom, built
from the perspective of a UKHSA Public Health Analyst.

## Research questions

- SQ1: Which countries had the highest total cases per million?
- SQ2: Which countries had the highest total deaths per million?
- SQ3: How did death rates change over time across continents?
- CQ: Which countries combine both high cases AND deaths —
  posing the greatest import risk to the UK?

## Key findings

Peru, Bulgaria, Hungary, Bosnia and Herzegovina, and Georgia
represent the highest combined severity risk. Peru and Bosnia
show extreme mortality relative to reported cases, indicating
significant undertesting and hidden import risk.
